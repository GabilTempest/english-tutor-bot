# 🇬🇧 Telegram Bot для менеджменту уроків англійської мови

Телеграм-бот, розроблений спеціально для організації та ведення занять між викладачем та учнем у Telegram-групі.

---

## ✨ Ключові можливості

1. **Робота прямо в групі Telegram:**
   * Додайте бота до спільного чату учня та викладача — всі сповіщення, розклад та ДЗ будуть на очах у обох учасників.
2. **💳 Облік оплачених занять:**
   * Поповнення балансу в 1 клік кнопками (`+1`, `+2`, `+4`, `+8` тощо) або командою `/pay 2`.
   * Біля запланованих уроків автоматично пишеться `(Оплачено 💳)` або `(Не оплачено ⏳)`.
   * **Плата не стягується** при скасуванні чи перенесенні! Баланс списується лише за підтверджені уроки.
3. **⚠️ Нагадування за 1 день до неоплаченого уроку:**
   * Якщо наближається урок, який не входить у передоплату, бот рівно за 24 години надсилає нагадування в групу із кнопками швидкого поповнення.
4. **🔔 Нагадування за 5 хвилин до початку:**
   * Бот автоматично перевіряє розклад і рівно за 5 хв надсилає повідомлення з постійним посиланням на зустріч (Google Meet, Zoom тощо) та актуальним домашнім завданням.
5. **❓ Опитування після уроку:**
   * Після завершення уроку бот запитує: «Чи відбувся урок?» (кнопки «Був» / «Ні»), фіксуючи статус та списуючи оплату.
6. **🔄 Перенесення уроків (і учнем, і викладачем):**
   * Будь-яка зі сторін може ініціювати перенесення запланованого уроку на іншу дату та час.
7. **📝 Домашнє завдання текстом:**
   * Учень або викладач можуть самостійно записати або доповнити домашнє завдання прямо текстом у чаті.
8. **🔒 Редагування та очищення історії по паролю:**
   * Очищення або ручне редагування записів захищено паролем адміністратора (`ADMIN_PASSWORD`). Пароль у чаті миттєво видаляється для безпеки.
9. **🔄 Повна синхронізація з приватними повідомленнями:**
   * Ви можете писати боту в приватні повідомлення — він покаже баланс, ДЗ та уроки вашої групи «Англійська Пн/Чт».
10. **🌍 Підтримка учнів за кордоном (часові пояси):**
    * Подвійний час: наприклад, *18:00 Київ / 17:00 Варшава*.

## ⚡ Автономна робота 24/7 на комп'ютері

Бот налаштований для безперервної автономної роботи:

| Файл | Що робить |
| :--- | :--- |
| `install_autostart.bat` | **Вмикає автозапуск разом з Windows** (ярлик у папці Автозавантаження). Бот запускається у фоні автоматично при включенні ПК. |
| `start_bot_silent.vbs` | Запускає бота у **прихованому фоновому режимі** (без чорного вікна консолі). |
| `run_forever.py` | Сторожовий процес (Watchdog): стежить за ботом і **автоматично перезапускає** його при перезавантаженні або збої інтернету. |
| `check_status.bat` | Показує, чи бот працює прямо зараз, та виводить останні логи. |
| `stop_bot.bat` | Зупиняє бота та фонові процеси. |
| `uninstall_autostart.bat`| Вимикає автозапуск разом з Windows. |

## 📋 Основні команди

| Команда | Опис |
| :--- | :--- |
| `/menu` | Відкрити головне меню з кнопками швидкої дії |
| `/balance` або `/pay` | Меню та облік оплачених занять (або `/pay 2` для швидкого додавання) |
| `/next` | Переглянути найближчий урок (час, статус, посилання, ДЗ) |
| `/hw` | Переглянути та записати домашнє завдання |
| `/lessons` | Відкрити список та повну історію уроків |
| `/reschedule` | Швидко перенести найближчий урок |
| `/link [url]` | Встановити або змінити постійне посилання на онлайн-дзвінок |
| `/schedule` | Регулярний розклад занять (або готові шаблони в 1 клік) |
| `/settings` | Налаштування регулярного розкладу, посилань та часових поясів |
